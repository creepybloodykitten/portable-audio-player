# Портативный автономный аудиоплеер c сенсорным управлением и локальным голосовым управлением на базе встроенного NPU.

Проект представляет собой законченное портативное устройство, разработанное полностью с нуля: от электрической принципиальной схемы и топологии печатной платы до низкоуровневых драйверов Linux, инференса нейросетей на NPU и графического интерфейса.
