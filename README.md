# Портативный Hi-Fi аудиоплеер с локальным голосовым управлением

Портативное мультимедийное устройство, разрабатываемое с нуля: от электрической схемы и 4-слойной печатной платы до низкоуровневых драйверов Embedded Linux, инференса нейросетей на аппаратном NPU и графического интерфейса.

---

## Аппаратная платформа

* **Вычислительный модуль:** Sipeed LicheeRV Nano W (чип **Sophgo SG2002**: RISC-V 1.0 ГГц / ARM Cortex-A53, 256 МБ SIP DRAM, встроенный NPU 1 TOPS, Wi-Fi 4 / BLE 5.0).
* **Цифро-аналоговый преобразователь:** **TI PCM5102A** (32-бит / 384 кГц, аппаратный PLL, SNR 112 дБ, DirectPath без выходных разделительных конденсаторов).
* **Усилитель для наушников:** **TI TPA6132A2** (DirectPath стерео 25 мВт на канал @ 16 Ом, дифференциальный вход, подавление щелчков Pop-and-Click).
* **Аналоговая фильтрация:** Конденсаторы C0G (NP0) в звуковом тракте для исключения нелинейных искажений.
* **Дисплей:** IPS сенсорный экран с контроллером **ST7701S** (интерфейс MIPI-DSI 2 Data + 1 Clock lane, емкостный тачскрин по I2C).
* **Подсистема питания:**
  * **IP5306** — контроллер заряда 2.1 А для одного Li-Pol элемента + синхронный повышающий DC-DC конвертер 5 В 2.4 А.
  * **XC6220B331PR-G** — ультрамалошумящий LDO (3.3 В, 1 А) для изоляции аналогового питания звукового тракта от цифровых шумов и DC-DC пульсаций.
  * **TI INA219A** — прецизионный I2C-монитор тока и напряжения с шунтом для контроля АКБ (Fuel Gauge).
  * **LP803450** — Li-Pol аккумулятор (3.7 В, 1500 мА·ч) с платой защиты PCM.
* **Органы управления и разъемы:**
  * Инкрементальный энкодер **EC11** со встроенной кнопкой (регулировка громкости, Play/Pause).
  * 3 боковые тактовые кнопки с металлическими упорными кронштейнами (Power, Next Track, Voice Input).
  * 3.5 мм аудиовыход **Same Sky (CUI) SJ-3524-SMT-TR** с фиксирующими штифтами.
  * USB Type-C для зарядки и прошивки.
