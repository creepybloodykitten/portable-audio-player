# Органы управления (User Controls)

В документе описаны элементы физического управления плеером: инкрементальный энкодер громкости и тактовые кнопки.

---

## 1. Состав органов управления

1. **Инкрементальный поворотный энкодер (EC11):**
   - Плавная регулировка уровня звука с тактильными щелчками (detents).
   - Квадратурный выход (каналы A и B с фазовым сдвигом 90°).
   - Встроенная кнопка нажатия (Switch) для функций Mute / Play-Pause / Select.
2. **Тактовые кнопки:**
   - Кнопка питания (`BTN_PWR`).
   - Кнопка воспроизведения (`BTN_PLAY_PAUSE`).
   - Опциональные кнопки перелистывания треков (Next / Prev).

## 3. Таблица подключений к SoC

| Элемент | Сигнал (Net) | Пин SoC | Роль | Тип входа |
| :--- | :--- | :--- | :--- | :--- |
| Энкодер Канал A | `ENC_A` | GPIO | Определение направления и шага вращения | Прерывание по обоим фронтам (Edge Interrupt) |
| Энкодер Канал B | `ENC_B` | GPIO | Определение фазы (направления вращения) | Чтение состояния |
| Кнопка энкодера | `ENC_SW`| GPIO | Нажатие на крутилку | Вход с подтяжкой к 3.3V |
| Кнопка воспроизведения | `BTN_PLAY_PAUSE` | GPIO | Старт / Пауза воспроизведения | Вход с подтяжкой к 3.3V |
| Кнопка питания | `BTN_PWR` | IP5306 KEY | Включение / выключение питания | Вход контроллера питания |

## 4. Схемотехника и борьба с дребезгом контактов (Debouncing)

Механические контакты энкодеров и кнопок подвержены дребезгу (Contact Bounce) в течение 1–5 мс при переключении. Для надежной работы применяется аппаратная или комбинированная фильтрация:

```
          3.3V
           │
          [R_pull: 10k]
           │
  Сигнал ──┴──[R_filt: 1k]──┬────► К пину GPIO SoC
                            │
                         [C_filt: 10nF]
                            │
                           GND
```

* **Подтягивающие резисторы (Pull-up):** 10 кОм к шине 3.3V (фиксируют высокий уровень в разомкнутом состоянии).
* **RC ФНЧ (Low-Pass Filter):** Резистор 1 кОм и керамический конденсатор 10 нФ образуют фильтр нижних частот с постоянной времени $\tau = R \times C = 1000 \cdot 10 \cdot 10^{-9} = 10\ \mu\text{s}$.
  * *Зачем конденсатор 10 нФ:* Срезает ультракороткие высокочастотные импульсы искрения и дребезга контактов, защищая процессор от лавины ложных прерываний.
  * Окончательная доочистка дребезга реализуется в драйвере ядра Linux программным таймером debouncing (стандартный драйвер `rotary-encoder` в Linux kernel).
